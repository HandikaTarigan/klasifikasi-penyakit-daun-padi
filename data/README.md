# Dataset

Gambar diambil dari [Rice Leaf Disease Classification India](https://huggingface.co/datasets/Project-AgML/rice_leaf_disease_classification_india) melalui library `datasets` di Google Colab. Gambar mentah tidak disalin ke repositori supaya ukurannya tidak terlalu besar.

Dataset awal berisi 5.932 gambar dalam empat kelas penyakit: Bacterialblight, Blast, Brownspot, dan Tungro. Setelah 1.180 duplikat identik dihapus, tersisa 4.752 gambar. Pembagian training, validation, dan testing tercatat di `reports/pembagian_dataset.csv`.

Lisensi yang dicantumkan pada halaman dataset adalah CC BY 4.0. Sumber dataset perlu tetap dicantumkan saat digunakan.
